# AdDisplay - Платформа цифровой рекламы

Современная платформа для размещения рекламы на цифровых экранах: грузовики, уличные дисплеи, экраны рядом со скамейками и другие поверхности.

## 🚀 Возможности

- **Загрузка медиа**: Поддержка изображений и видео для рекламных кампаний
- **Гибкие настройки**: Выбор времени показа, локаций, количества показов
- **Модерация**: Система одобрения рекламы администраторами
- **Личный кабинет**: Отслеживание статуса и эффективности кампаний
- **Красивый UI**: Анимированные эффекты, градиенты, современный дизайн

## 🛠 Технологии

- **Next.js 14** - React фреймворк с App Router
- **TypeScript** - Типизированный JavaScript
- **Tailwind CSS** - Утилитарный CSS фреймворк
- **Framer Motion** - Библиотека для анимаций
- **Zustand** - Управление состоянием
- **React Hot Toast** - Уведомления
- **Lucide React** - Иконки

## 📦 Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd ad-display-platform

# Установить зависимости
npm install

# Запустить сервер разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 📱 Основные страницы

- `/` - Главная страница с информацией о платформе
- `/create-campaign` - Создание новой рекламной кампании (5 шагов)
- `/dashboard` - Личный кабинет пользователя
- `/admin` - Панель администратора для модерации

## 🚦 Процесс работы

1. **Создание кампании**: Пользователь заполняет форму из 5 шагов
2. **Модерация**: Кампания отправляется на проверку администратору
3. **Одобрение/Отклонение**: Администратор проверяет и принимает решение
4. **Запуск**: Одобренная кампания запускается автоматически
5. **Мониторинг**: Пользователь отслеживает статистику в личном кабинете
