# DigitalAds - Платформа цифровой рекламы

Современная платформа для размещения рекламы на цифровых экранах грузовиков, автобусных остановок, торговых центров и других локаций.

## 🚀 Основные возможности

### Для рекламодателей:
- **Простая загрузка медиа** - поддержка видео (MP4, MOV, AVI, WebM) и изображений (JPG, PNG, GIF)
- **Гибкие настройки кампании** - выбор времени показа, количества повторов и локаций
- **Система модерации** - все рекламные материалы проходят проверку перед публикацией
- **Детальная аналитика** - статистика показов, кликов и эффективности кампаний
- **Управление бюджетом** - контроль расходов и планирование затрат

### Для администраторов:
- **Панель модерации** - быстрое одобрение или отклонение рекламных кампаний
- **Система поиска и фильтрации** - удобный поиск по кампаниям
- **Детальный просмотр** - полная информация о каждой кампании
- **Причины отклонения** - возможность указать детальную причину отказа

## 🛠 Технологический стек

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Анимации**: Framer Motion
- **Загрузка файлов**: React Dropzone
- **Иконки**: Lucide React
- **Стилизация**: CSS градиенты, анимации, backdrop-blur эффекты

## 📦 Установка и запуск

1. **Клонирование репозитория**
   ```bash
   git clone [repository-url]
   cd digital-ads-platform
   ```

2. **Установка зависимостей**
   ```bash
   npm install
   ```

3. **Запуск в режиме разработки**
   ```bash
   npm run dev
   ```

4. **Открыть в браузере**
   ```
   http://localhost:3000
   ```

## ⚡ Основные компоненты

```typescript

  'image/*': ['.jpeg', '.jpg', '.png', '.gif'],
  'video/*': ['.mp4', '.mov', '.avi', '.webm']
};
```

### Анимации
```typescript
// Пример анимации появления
<motion.div
  initial={{ opacity: 0, y: 50 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.8 }}
>
```

### Градиенты
```css
/* Основной градиент фона */
bg-gradient-to-br from-slate-900 via-purple-900 to-slate-900

/* Градиенты кнопок */
bg-gradient-to-r from-purple-600 to-pink-600
```
